LokSetu (Constituency OS)

A strategic data-driven platform for Members of Parliament

📌 The Problem Statement: People's Priorities

Members of Parliament (MPs) receive thousands of unstructured development requests daily via letters, social media, and voice. However, they lack an objective, data-driven way to consolidate this chaotic feedback, extract actionable themes, and weigh individual complaints against real geographical demand.

🎯 The Challenge

Build an AI platform to ingest citizen suggestions, extract themes, map demand hotspots, and combine this with local demographic data to rank high-priority development works objectively.

Strategic Vision: Turn unstructured, multilingual citizen feedback into real-time priority intelligence, enabling MPs to optimize budget allocation instantly.

💡 Our Solution

LokSetu (Bridge of the People) is an AI-powered command center designed specifically for MPs. It takes the chaos of multilingual, unstructured citizen complaints and transforms it into a sleek, real-time dashboard.

Instead of reading 1,000 WhatsApp messages, the MP views a heatmap highlighting that "Water Supply in Ward 3" is a critical, high-density crisis, cross-referenced with real ward population data.

Core Features

  • The "Pulse" Ingestion: Accepts raw, unstructured, colloquial citizen inputs.
  • AI Structuring Engine: Uses an LLM to automatically extract the Issue Category, Sentiment, Ward Location, and Urgency from messy text.
  • Data-Driven Priority Algorithm: Ranks issues not just by raw volume, but by a weighted density calculation.
  • Command Center Dashboard: A lightning-fast visual interface for the MP to allocate funds and direct authorities.
Priority Score = (Urgency_Score * 0.6) + ((Complaint_Count / Ward_Population) * 10,000 * 0.4)

🛠 Tech Stack & Architecture (24-Hour Strategy)

To win a 24-hour hackathon, we are prioritizing Speed, Reliability, and "Static Realism" to ensure a flawless, crash-proof demo.

⚡ Vanilla JS SPA

Pure HTML, CSS, and Vanilla JavaScript. An SPA structure ensures zero page reloads (no flashing white screens), providing a high-fidelity application experience without bundler configuration delays.

⚡ Supabase Backend

Provides a PostgreSQL database with auto-generated REST APIs. Eliminates writing custom server code, allowing direct secure data queries from the frontend via the Supabase JS client.

⚡ Static Realism

Bypasses slow, rate-limited live government APIs. Instead, we use real Delhi NCR Ward Demographics imported into Supabase as a CSV, providing instant, local reality to the judges.

⚡ AI Synthesis

Generates realistic dummy citizen complaints and tags them to actual ward locations, ensuring our visualization feels native to Delhi geography during the live evaluation.
